How It Works

Pass a native element constructor as the base to mixin(), then register with the extends option:

// The class extends a real HTMLButtonElement
class IconButton extends mixin(HTMLButtonElement) { ... }

// Register with { extends: 'button' }
wiet({ name: 'icon-button', extends: 'button' }, IconButton);

// Use with the `is` attribute in HTML
// <button is="icon-button" icon="bi-star" label="Star"></button>
Note: Customized built-in elements require a polyfill in Safari. The @ungap/custom-elements polyfill handles this.
